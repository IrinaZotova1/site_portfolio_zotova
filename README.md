# site_portfolio Зотова Ирина 4-мд-5
JS-функционал:
• бургер-меню с aria-expanded и автозакрытием при клике по ссылке;
• анимация появления заголовка hero и аватара при загрузке страницы;
• скрытие/показ хедера при скролле (через lastScrollY);
• IntersectionObserver для fade-up и reveal-line анимаций при прокрутке;
• курсор-превью изображений проектов (только для устройств с мышью);
• параллакс фоновых фигур через requestAnimationFrame и data-speed;
• переворот карточек-папок по клику и закрытие при клике вне карточки;
• интерактивное рисование на canvas (мышь + тач, поддержка devicePixelRatio,
  кнопка очистки);
• всплывающее модальное окно при прокрутке до конца секции «Процесс»
  с закрытием по клику, оверлею и клавише Escape.
